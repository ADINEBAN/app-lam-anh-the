# App Làm Ảnh Thẻ

Ứng dụng hỗ trợ tạo ảnh thẻ từ ảnh chân dung.

## Mục tiêu

- Tải ảnh chân dung lên
- Cắt ảnh theo kích thước ảnh thẻ phổ biến
- Thay nền trắng / xanh
- Chỉnh kích thước và xuất ảnh để in hoặc nộp hồ sơ

## Kích thước dự kiến

- 3x4 cm
- 4x6 cm
- 2x3 cm
- Ảnh hộ chiếu / visa

## Trạng thái

Repo vừa được khởi tạo. Sẽ cập nhật công nghệ và hướng dẫn chạy sau khi chốt stack.
